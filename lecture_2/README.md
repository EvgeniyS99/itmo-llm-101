# Lecture 2: LLM Serving

This lecture covers local LLM deployment, model quantization, inference backends, and OpenAI-compatible APIs. The practical materials use Ollama, Hugging Face models, and generation benchmarks.

## Learning Outcomes

After this lecture, participants will be able to:

- explain KV-cache usage, batching, and common transformer inference bottlenecks;
- compare quantization strategies and their impact on quality, memory, and speed;
- measure latency, throughput, memory consumption, and generation quality;
- serve open-source models with Ollama, vLLM, and TGI;
- work with OpenAI-compatible inference APIs.
