# Lecture 1: Introduction to LLMs

This lecture introduces large language models, their core capabilities, the main stages of training, and the ideas behind modern generative AI systems.

## Learning Outcomes

After this lecture, participants will be able to:

- describe the architecture of GPT-like transformer models;
- explain autoregressive token generation at a high level;
- distinguish the main stages of LLM training and inference;
- identify the capabilities and limitations of modern generative models.
