# Lectures 5–6: FastAPI and Gradio

These lectures cover application interfaces and deployment for LLM systems with FastAPI and Gradio. The final homework combines LangChain, LangGraph, model serving, streaming, persistence, and user-facing interaction in a complete project.

## Learning Outcomes

After these lectures, participants will be able to:

- design an asynchronous FastAPI backend for an LLM application;
- support multiple users and persistent conversation state;
- build user-facing interfaces with Gradio and Jinja templates;
- connect an application to locally served or OpenAI-compatible models;
- trace graph, chain, tool, and model execution with Langfuse;
- debug and maintain an end-to-end LLM service.

The final assignment references a separate capstone application repository. The application is maintained independently and is not included in this repository.
