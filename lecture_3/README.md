# Lecture 3: Introduction to LangChain

This lecture introduces LangChain building blocks: chat models, prompt templates, streaming, batching, callbacks, retries, structured output, and tool calling. The homework applies these concepts to a simple math tutor chain.

## Learning Outcomes

After this lecture, participants will be able to:

- compose reusable LLM pipelines with LangChain;
- configure prompts, chat models, streaming, batching, callbacks, and retries;
- validate model responses with structured output;
- define and invoke tools from an LLM workflow;
- route requests between plain responses and tool execution.
